**阈值修订（有据）**：初版沿用工笔/线描类阈值 `edge 0.12–0.35`，实测 0.061–0.091 全部越界。原因是本风格浅景深 + 柔焦 + 大块渐变，高频边缘天然低于线描类。按实测下调为 `0.05–0.11`；饱和度区间同步由 `0.22–0.58` 调整为 `0.18–0.45`。修订写在 `scripts/gen_style_packs.py` 的条目里，可复现。

## 4. 残留风险

1. **人物占比过高**：12 张里 11 张有主体人物。即使 06/07/08/09 返工后，仍靠"远处小人"换取景别变化，真正的空镜只有部分成立。原因是 `compile_image_prompt` 固定追加 `one clear hero silhouette` 与 `a formed expressive face` 两条正向锚点，空镜主体会被拉回人物。
2. **面部偏偶像化**：02/07/12 皮肤过于平滑、五官偏"娃娃脸"，与 `negative_constraints` 里的 `idol face` 相悖。CFG 1.0 下负向词不生效，只能靠正向描述压，目前压不住。
3. **色板单色倾向**：青碧 + 墨黑 + 金线占绝对主导，绛红只在 03/12 出现。色板校验通过，但整板偏"一色流"，作为参考板会限制后续样片色彩。
4. **发丝接片**：02 头顶发片与发际线交界有轻微接缝，Wan 运动时可能被放大。
5. **角色一致性**：项目不具备同脸能力，本包只锁定质感与光照，不承诺跨镜头同脸。
