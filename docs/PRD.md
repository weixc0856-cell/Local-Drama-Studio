# 01 · PRD — Local-Drama-Studio Product v1.0

> 文档状态：`DECISION` / v1.0 产品方向冻结（2026-11-03）。
> **冻结的是产品方向、内容范围、技术栈与流程边界；不是宣布所有能力已验证。**
> 历史技术证据保留在 `docs/R0_*` ~ `docs/R3_*`，不合并、不删除。

## 1. 一句话定位

面向抖音和小红书的**东方视觉内容生产工具**：用本地 AI 把诗词、古典人物与神话意象，稳定制作成有画面、有声音、有字幕、有节奏的竖屏短视频。

产品名：**Local-Drama-Studio · Product v1.0**
工作名：东方视觉内容工作室。

## 2. 要解决的问题

不是“再做一个 AI 图片生成器”，而是：

1. 每次创作都从零折腾模型、参数、工作流，无法积累。
2. 图片能生成，但缺少完整的声音、字幕、节奏与可发布包装。
3. 单条视频的制作流程不可复用，失败后无法定位。
4. 视觉资产（人物、场景、风格、提示词）没有台账，无法持续迭代。

## 3. 目标用户与场景

- 单人创作者或 2-3 人小团队。
- 本地工作站：Intel Arc A750 8 GB / 64 GB RAM / Windows 11。
- 需要“晚上跑一批、第二天人工审核发布”的内容节奏。
- 不以专业动画工作室、连续剧平台或数字人直播为目标。

## 4. 第一阶段产品目标

从一个主题或篇目开始，完成单篇作品的完整生产：

```text
主题/文本 → 策划 → 分镜 → 视觉规范 → 静帧 → 必要动态镜头
→ 旁白/朗诵 → 音乐/音效（可选）→ 字幕 → 合成 → 质量检查
→ 平台封面/标题/文案 → 人工审核 → 发布 → 数据记录
```

第一阶段只要求**单篇完整、稳定、值得发布**，不要求自动批量发布。

## 5. 内容范围

### 5.1 三个内容方向

| 方向 | 说明 | 初始测试占比（实验，不是市场结论） |
|---|---|---|
| 东方山水与诗词意境 | 《春江花月夜》、唐诗宋词、山水空镜 | 50% |
| 古典仕女与原创东方女性角色 | 人物设定、服饰、情绪、短视频叙事 | 30% |
| 东方神话与幻想视觉 | 《洛神赋》《山海经》、神话意象 | 20% |

比例是**实验分配**，不是已验证的市场策略；根据平台数据调整。

### 5.2 代表性内容

- 《春江花月夜》（已有 38 秒样片，`PASS_VERIFIED`）
- 《洛神赋》（尚未制作，`NOT_RUN`）
- 《山海经》与唐诗宋词（尚未制作，`NOT_RUN`）

## 6. 交付形式

- 竖屏短视频，母版 1080×1920，9:16。
- 诗词朗诵 + 视觉、原创人物视觉、传统文化主题短片。
- 母版统一，平台适配封面/标题/文案/话题，不重新剪辑正片。
- 人工审核后发布；v1.0 不做自动发布。

## 7. 范围：做什么，不做什么

### 做

- 单篇 30-60 秒竖屏作品（默认；90 秒仅作实验）。
- 4-6 张静帧 + 1-2 段 Wan 英雄镜头（当前实测配方）。
- CosyVoice 旁白/朗诵。
- 字幕、封面、标题、正文、话题。
- 资产台账、授权台账、成本记录、平台数据记录。
- 人工审核与人工发布。

### 不做（v1.0）

- 自动发布、自动涨粉、无人值守账号运营。
- AI 数字人、口型同步、复杂人物动画、多角色长期一致性保证。
- 原生 1080p 视频生成、SeedVR2 或新视频模型。
- 多模型并行生产、Remotion、复杂 Agent 框架。
- 商品转化链路与商业投放系统。
- 以播放量单指标判断风格成败。

## 8. 成功标准

### 产品/流程成功

1. 单篇作品可以从主题走到可发布 MP4。
2. 技术检查通过：1080×1920、音画完整、字幕可读、无黑帧/损坏帧。
3. 素材、参数、模型版本、许可证可追溯。
4. 失败可降级、可重跑，不需要重做整条链路。
5. 成本可记录，能判断是否适合夜间批次。

### 不承诺

- 账号增长、播放量、涨粉、商业转化。
- 某一种画风一定受欢迎。
- 人物跨镜头完全一致。

**技术能力足以支撑内容测试，但不能保证账号增长。**

## 9. 商业假设（未验证）

- 东方视觉 + 诗词朗诵的竖屏内容存在稳定受众。
- 单人或小团队可以靠“母版 + 平台适配”持续产出。
- 后续可通过品牌合作、定制内容或商品橱窗变现。
- 以上均为假设，`NOT_RUN`，不得写成已验证。

## 10. 风险

| 风险 | 影响 | 应对 |
|---|---|---|
| 文化事实与艺术想象混淆 | 误导、口碑风险 | 内容分级标注；历史/原文/想象分开 |
| AI 内容标识与平台合规 | 限流、下架 | 发布前按平台规则标识；保留素材授权台账 |
| 人物一致性不足 | 系列内容断裂 | 先做静态人物资产管理；不承诺跨镜头一致 |
| Wan 精确动作不可靠 | 叙事受限 | 用静帧推拉/后期合成；Wan 只做推近类镜头 |
| 单条成本高 | 无法持续 | 4-6 静帧 + 1 Wan；控制时长 |
| 字体/音乐/模型授权 | 法律风险 | 统一授权台账；商用前复核 |
| 平台策略变化 | 发布受阻 | 人工审核与适配，不做自动发布 |

## 11. 冻结边界

### 冻结

- 尚未验证的性能指标。
