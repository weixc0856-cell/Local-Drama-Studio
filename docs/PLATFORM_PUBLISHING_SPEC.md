# 05 · PLATFORM_PUBLISHING_SPEC — 抖音 / 小红书

> 文档状态：`DECISION` / v1.0 发布规范冻结。
> **v1.0 不实现自动发布，不接平台 API；发布与数据记录由人工完成。**
> 平台规则会变化，发布前以平台当期规则为准。

## 1. 共同母版

所有平台共用一条母版正片，不为平台重新剪辑主线：

| 项 | 母版规格 |
|---|---|
| 画幅 | 9:16 |
| 分辨率 | 1080×1920 |
| 帧率 | 24fps |
| 编码 | H.264，yuv420p，CRF 18 |
| 音频 | AAC 48 kHz，192 kbps |
| 容器 | MP4，faststart |
| 时长 | 30-60 秒（最长 90 秒仅实验） |
| 字幕 | 软字幕 + 可选烧录 |

平台差异体现在**封面、标题、正文、话题、发布记录**，不改正片。

## 2. 平台差异

| 维度 | 抖音 | 小红书 |
|---|---|---|
| 内容包装 | 前 3 秒吸引力、节奏、完播 | 封面、标题、审美、收藏价值 |
| 重点指标 | 完播、互动、分享 | 点击、收藏、关注、互动 |
| 封面 | 视频首帧/独立封面 | 独立设计封面（常用 3:4） |
| 文案 | 简洁、强吸引 | 标题 + 正文 + 话题 |
| 发布节奏 | 连续测试 | 主题系列化 |
| 标题风格 | 短、直接、悬念 | 信息 + 审美 + 关键词 |

## 3. 封面规范

### 抖音

- 9:16 或 3:4 构图，主体居中偏上。
- 前 3 秒与封面一致，不标题党。
- 封面文字 ≤10 字，避免遮挡主体。
- 不出现平台禁止的诱导/虚假信息。

### 小红书

- 独立封面，建议 3:4；可另出 1:1。
- 封面文字 8-14 字，突出主题/情绪/知识点。
- 保留安全边距；不把字幕烧进封面。
- 封面风格与正片一致，不制造与内容不符的预期。

## 4. 标题与正文

### 标题

- 抖音：≤20 字，前 6 字给信息或悬念。
- 小红书：≤20 字标题 + 正文分段；关键词自然出现。
- 不使用“史上最”“百分百”“ guaranteed”等虚假承诺。
- 不把 AI 想象写成历史事实。

### 正文模板

```text
【原文】……（注明篇目/作者）
【意象】……（现代解读，注明“解读”）
【AI 视觉】本片画面为 AI 生成的艺术想象，不是历史复原。
（可选）制作：Local-Drama-Studio
```

### 话题

- 与内容直接相关：`#春江花月夜` `#古诗词` `#东方美学` `#AI视觉`。
- 不堆砌无关热词；遵守平台 AI 内容标识规则。

## 5. 合规要求

1. **AI 内容标识**：按平台当期规则标注；不默认“可以不标”。
2. **原创与授权**：不使用未经授权的影视角色、动画素材、他人作品。
3. **音乐/音效**：只用已登记授权的素材；v1.0 当前无 BGM。
4. **字体**：烧录字幕使用 Microsoft YaHei 需确认商用授权；公开发布建议换开源 CJK 字体。
5. **文化准确性**：原文、解释、历史事实、艺术想象分开标注。
6. **肖像/人物**：不使用真实人物肖像；原创角色不得影射真实个人。
7. **商业推广**：如涉及商品/广告，按平台规则标注。

## 6. 发布前检查清单

- [ ] 正片为 1080×1920 / 24fps / 音画完整 / 无黑帧
- [ ] 字幕无错字、时间对齐
- [ ] 音频清晰、无削波
- [ ] 封面与内容一致，无标题党
- [ ] 标题/正文/话题已按平台定制
- [ ] AI 内容标识已按平台规则处理
- [ ] 字体/音乐/素材授权已登记
- [ ] 原文与解释标注正确
- [ ] 人工完整看片一遍

  "url": "",
  "duration_seconds": 0,
  "cover_path": "",
  "master_path": "",
  "ai_label": true,
  "theme": "",
  "style": "",
  "views": 0,
  "completion_rate": 0,
  "avg_watch_seconds": 0,
  "likes": 0,
  "comments": 0,
  "saves": 0,
  "shares": 0,
  "follows": 0,

- 平台数据以发布后 24h / 72h / 7d 三个窗口记录（若可得）。
- 不把单条视频的数据当成风格结论；至少 3-5 条同变量样本再判断。

## 9. 不承诺

- 发布即有播放/涨粉/转化。
- 某一封面或标题模板长期有效。
- 平台规则不变。

发布策略必须随平台数据和规则调整，不能写死成系统逻辑。
