# 05 · 平台发布与舒适区（抖音 / 小红书）

> 状态：`DECISION` / 2026-11-12 由 `PLATFORM_PUBLISHING_SPEC.md` 与 `PLATFORM_COMFORT_ZONE.md` 合并。
> **v1.0 不实现自动发布、不接平台 API；发布与数据记录由人工完成。** 平台规则会变，发布前以当期规则为准。

## 1. 母版

所有平台共用一条母版正片，不为主线重新剪辑：

| 项 | 规格 |
|---|---|
| 画幅 | 9:16，1080×1920 |
| 帧率 | 24 fps |
| 编码 | H.264 / yuv420p / CRF 18 |
| 音频 | AAC 48 kHz，192 kbps |
| 容器 | MP4，faststart |
| 时长 | 30–60 s（最长 90 s 仅实验） |
| 字幕 | 软字幕 + 可选烧录 |

平台差异只体现在封面、标题、正文、话题与发布记录。

## 2. 平台规格与差异

| 项 | 抖音 | 小红书 |
|---|---|---|
| 视频画幅 | 9:16 | 3:4（1080×1440）或 9:16 |
| 时长 | 15–30 s 完播最好，不低于 7 s | 15–60 s，推荐约 30 s |
| 编码 | 24/30 fps H.264 | 30 fps H.264，8–12 Mbps |
| 图文 | 6–9 张 9:16 | 3:4 封面，6–9 张（上限 18），单张 ≤5 MB |
| 封面 | 安全区约 1080×1464，文字 ≤10 字 | 3:4，标题 10–15 字，文字 ≤30% |
| 关键指标 | 前 3 s 完播、整体完播、复看、收藏 | 封面点击、收藏、评论质量 |
| 标题 | ≤20 字，前 6 字给信息/悬念 | ≤20 字 + 正文分段 |

## 3. 舒适区（A 级）

| 内容 | 平台 | 规格 | 生产时间 |
|---|---|---|---|
| 一诗一画 / 山水空镜 | 双平台 | 15–30 s，4–6 镜，1 个纯风景 Wan hero，其余静帧推拉+云水运动 | 1–1.5 h/条 |
| 动态国画壁纸 / 开屏 loop | 双平台 | 10–15 s，1–3 镜，循环 | 30–50 min/条 |
| 3:4 图文审美笔记 | 小红书 | 6–9 张关键帧 + 书法/诗句排版 + 过程参数 | 20–40 min/条 |
| 节气 / 古建一角 / 水墨过程 | 双平台 | 图文 + 15 s 视频组合 | 30–60 min/条 |
| 文化科普 / 名句解读 | 双平台 | 30–60 s，静帧/地图/书法 + 旁白 | 1.5–2 h/条 |

条件可用（B 级）：人物抒情短片（近景静帧 + 背景运动 + 慢推，不能动作/对白）；建筑亭台（必须 2.5D 分层视差）；品牌氛围片（空镜 + 产品静帧 + 光效）。

不舒适区（C 级，不接）：剧情短片（动作/对白/连续空间）、2–5 分钟全生成动画、角色跨镜头同脸、4K/60 fps、结构必须精确的建筑/产品商业片。

## 4. 视频模板（15–30 s）

```text
画幅：9:16，1080×1920，24/30 fps
镜头：4–6 个；1 个纯风景 Wan hero（约 5–6 s）；其余静帧 8–12% 推拉 + 云/水/树叶局部运动
转场：普通切点 0.5 s 叠化；匹配剪辑保持硬切
旁白：3–5 句，逐句字幕；总旁白 8–15 s
声音：持续环境声 + BGM（ducking）；切点 whoosh
第一帧：诗句/标题/最强画面，3 秒内给出信息
结尾：留 1–2 s 尾音/尾画面，方便循环
标签：AI 生成内容声明
```

## 5. 图文笔记模板（3:4）

```text
比例：1080×1440，整篇统一
张数：6–9 张
第 1 张：封面（诗句/标题 10–15 字，文字 ≤30%）
第 2–3 张：最强画面/细节
第 4–6 张：不同景别/局部
第 7–9 张：过程、参数、before/after、AI 声明
标题：10–15 字，具体利益/审美点
正文：诗句/出处 + 画面说明 + 制作方法
```

## 6. 标题与正文

- 不用「史上最」「百分百」等虚假承诺；不把 AI 想象写成历史事实。
- 正文模板：

```text
【原文】……（注明篇目/作者）
【意象】……（现代解读，注明“解读”）
【AI 视觉】本片画面为 AI 生成的艺术想象，不是历史复原。
```

- 话题与内容直接相关（`#古诗词` `#东方美学` `#AI视觉`），不堆无关热词。
- 封面与内容一致，不标题党；字幕不烧进封面。

## 7. 合规

1. **AI 标识**：按平台当期规则主动标注（《人工智能生成合成内容标识办法》2025-09-01 施行）；不得篡改/隐匿平台标识。
2. **原创与授权**：不使用未授权的影视角色、动画素材、他人作品。
3. **音乐/音效**：只用已登记授权素材；CC BY 曲目（Jason Shaw《Green Leaves》《Serenity》）必须在正文/简介署名。不得抽取电影/动画原声。
4. **字体**：新构建字幕使用思源黑体（OFL 1.1）；历史成片的 Microsoft YaHei 需在公开发布前替换。
5. **文化准确性**：原文、解释、历史事实、艺术想象分开标注。
6. **肖像**：不使用真实人物肖像；原创角色不得影射真实个人。

## 8. 发布前检查清单

- [ ] 正片 1080×1920 / 24 fps / 音画完整 / 无黑帧
- [ ] 字幕无错字、时间对齐
- [ ] 音频清晰、无削波
- [ ] 封面与内容一致，无标题党
- [ ] 标题/正文/话题已按平台定制
- [ ] AI 内容标识已处理
- [ ] 字体/音乐/素材授权已登记；CC BY 署名已写
- [ ] 原文与解释标注正确
- [ ] 人工完整看片一遍
