# 新中式方向：当代设计语言，不是画风复刻（2026-11-06）

> 触发：水墨拟古的参考板两次试片仍不合格。问题不在笔触，而在方向——把「新中式」做成了古画赝品。
> 结论：`oriental.modern_chinese` 改为 **当代新中式（苏州博物馆方向）**：写实材质 + 几何抽象 + 大面积留白，不做水墨皴法。

## 1. 定义

新中式不是某个历史画派，而是「用当代设计语言、材料与构图秩序，解构并重塑中国传统文化的气韵」。判断标准是「意在笔先、形简意深」，不是符号密度。

## 2. 三条可执行规则

1. **单焦点**：一张画面只讲一件事。山水就纯山水，亭子就一个空亭，孤舟就留出极空的水面。
2. **哑光低饱和**：天青、月白、黛蓝、竹青、赭石、玄黑做灰度沉淀；材质是纸、绢、石、木、白墙，禁止 3D 塑料高光与 HDR。
3. **计白当黑**：至少 40% 画面是纯净留白（雾、天空、静水、白墙），留白本身就是内容。
4. **无界通栏**：不要角花、回字纹、云纹边框、游戏 UI 描边；边界靠留白自然形成。

## 3. 参考系（只取方法，不复刻作品）

- **建筑**：贝聿铭苏州博物馆——粉墙黛瓦抽象为几何折线、玻璃与片石假山，「以壁为纸，以石为绘」；王澍象山校区——旧砖瓦与清水混凝土的粗粝质感。
- **影像**：《刺客聂隐娘》式大气漫射光、晨暮微光、长镜头、自然景深；拒绝 CG 高反差。
- **平面**：东方极简的纯色底、毫米级朱红印章、细线排版；不要毛笔特效字。

## 4. 落到 `oriental.modern_chinese`

| 维度 | 新取值 |
|---|---|
| 媒介 | 电影感建筑/景观摄影，哑光表面，细颗粒，自然色 |
| 构图 | 单焦点；≥40% 空景；圆洞门/细瓦檐/格栅抽象为几何；非对称、无边框 |
| 光线 | 阴天或清晨漫射光，无高光，远处薄雾 |
| 色板 | 月白 `#E9E6DE`、黛瓦 `#3F4449`、天青 `#9DB3AE`、竹青 `#6F8574`、墨 `#2E3134` |
| 尺幅 | 建筑与人保持小尺度，禁止宫殿式体量 |
| 镜头 | 35–40mm、深景深、慢速 static / dolly_in / tilt / tracking |
| 运动 | 雾移、水波、竹影；不堆叠运动 |

明确禁止：红柱蓝瓦、飞檐斗拱、灯笼祥云、雕花边框、景区仿古亭、3D 渲染光泽、HDR、镜头光斑、微缩模型感、移轴。

## 5. 与宋画研究的关系

`SONG_AESTHETIC_STUDY.md` 保留为美学背景：平淡天真、留白、宋瓷色仍然成立；但 **不再使用水墨皴法、绢本拟古** 作为生成媒介。宋画提供的是克制与空间观，不是表面质感。

## 6. 验收口径

- 客观：饱和度 ≤0.15、边缘密度 0.05–0.20、亮度不爆高光、无黑边。
- 主观：第一眼是当代空间/摄影，而不是「古画」或「景区」；画面 ≥40% 为空；只有一个视觉焦点；没有任何装饰边框。
