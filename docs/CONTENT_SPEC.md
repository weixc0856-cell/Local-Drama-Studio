# 03 · CONTENT_SPEC — 视觉、人物、声音与视频规范

> 文档状态：`DECISION` / v1.0 内容规范冻结（2026-11-03）。
> 视觉基线来自 R1；竖屏与成片规格来自 R3。历史细节见 `docs/R1_VISUAL_DESIGN.md`、`docs/R3_TEST_REPORT.md`。

## 1. 适用范围

- 抖音、小红书竖屏短视频。
- 东方山水与诗词意境、古典仕女与原创东方女性角色、东方神话与幻想视觉。
- 母版 9:16，1080×1920；默认 30-60 秒，最长 90 秒仅作实验。

## 2. 视觉系统

### 2.1 色板

| 名称 | 色值 | 用途 |
|---|---|---|
| 墨黑 | `#10161C` | 阴影、远山剪影 |
| 靛青 | `#1E3247` | 夜空、江水暗部 |
| 月白 | `#DCE6EA` | 月光、水面高光、雾 |
| 青绿 | `#4F6F63` | 近岸植物、苔石 |
| 雾灰 | `#8A9499` | 中景雾气、空气透视 |
| 淡金 | `#C9A76A` | 晨曦、月光边缘 |
| 胭脂淡 | `#8E5B5B` | 花瓣点缀（≤5%） |

禁止高饱和青橙调色、霓虹、纯橙/纯紫游戏 CG 色。

> 本节色板是 R1 建立的水墨/自然纪实基线，对应 `ink_wash` 风格的近似方向。双核心风格的完整色板、材质、线条与动画要求以 [`VISUAL_STYLE_SPEC.md`](VISUAL_STYLE_SPEC.md) 和 `config/styles.yaml` 为准；两者冲突时以该规范为准。

### 2.2 光照与质感

- 夜景：冷银蓝月光，低对比，薄雾贴水面；阴影保留细节。
- 晨曦：淡金 + 冷蓝阴影，晨雾更厚；不得过曝。
- 质感：35mm 细颗粒、轻微 halation、水墨远山 + 写实近景。
- 禁止塑料感、过度磨皮、游戏 CG 发光粒子。

### 2.3 建筑与自然

允许：唐代低矮木构、茅亭、石阶、木栏、乌篷小舟、江湾、沙洲、芦苇、青枫、花林、苔石、远山。

禁止：现代建筑/电线/路灯/玻璃幕墙、西方城堡/哥特、日式鸟居（本项目不用）、现代服饰、塑料/金属护栏、与唐代民间江景不符的器物。

### 2.4 摄影机语言

| 项 | 规范 |
|---|---|
| 帧率 | 24fps |
| 镜头 | 35mm / 50mm 等效为主，85mm 远景压缩 |
| 运镜 | 固定、缓慢推近、缓慢横移；禁止快速摇镜/手持晃动 |
| 景别 | 大远景、远景、中景、空镜 |
| 构图 | 三分法 + 留白；地平线不居中 |
| 人物 | 远景剪影；v1.0 不承诺正脸跨镜头一致 |

### 2.5 竖屏构图

- 9:16，主体居中偏上；顶部 10% 与底部 20% 视为平台 UI/字幕安全区。
- 不把 16:9 画面直接裁成 9:16；必须重新构图或生成。
- 单屏只承载一个视觉焦点；避免横向信息堆叠。
- 字幕区域与主体分离；月亮/远山不压在字幕安全区。

### 2.6 时间与空间逻辑

- 月亮：左侧低空 → 左上 → 上方 → 右侧落月。
- 河湾、远山、花林、孤舟保持同一空间关系；不换岸、不突然消失。
- 关键帧之间允许视角变化，不允许地理结构跳变。

### 3.1 双核心视觉风格（2026-11-03 收敛）

系统只支持两种核心视觉配置，不再扩展第三、第四种风格：

| 风格 id | 名称 | 视觉定位 | 状态 |
|---|---|---|---|
| `court_green_fine_line` | 宋代院体青绿工笔 | 绢本设色、石青石绿、细密线条、院体秩序；长卷横移与缓慢推近 | 规范/配置 `PASS_STATIC`；S2 片段 + 管线 B 28 s 样片 `PARTIAL`（技术通过，人工待审） |
| `ink_wash` | 东方写意水墨 | 生宣纸本、墨分五色、自然渗染、留白构图；墨迹与局部微动 | 规范/配置 `PASS_STATIC`；S2 片段 + 管线 A 20 s 分层样片 `PARTIAL`（技术通过，人工待审） |

规则：

- 两条管线共享底层技术设施（ComfyUI、FLUX/Wan、FFmpeg、调度、存储），但提示词、静态质量检查表、图层与动画策略相互独立；差异由 `config/styles.yaml` 配置，不改代码。
- 不把两种风格合并成一个大提示词，再靠少量参数切换。
- 每期绑定风格后冻结快照；修改全局预设不影响历史期数。
- 风格细节、验收标准与动画路线见 [`VISUAL_STYLE_SPEC.md`](VISUAL_STYLE_SPEC.md)。
- 不预设敦煌、国漫、写实人物等其他风格变体；当前没有第三种风格的计划。

## 4. 人物资产规范（未来，未验证）

每个角色必须建立：

```text
characters/<char_id>/
├─ sheet.png             # 定妆四视图/参考图
├─ front.png / side.png / back.png
├─ expressions/          # 表情参考
├─ wardrobe/             # 服装参考
└─ meta.json             # prompt、seed、模型/工作流版本、参考图 sha256、人工锁定状态
```

规则：

- 只重复提示词不构成一致性证据；必须使用参考图/编辑条件 + 人工确认。
- 人物锁定后才能进入分镜；锁定后不得静默改 seed/模型。
- v1.0 只承诺“可辨认、服装与气质连续”，不承诺像素级同一张脸。
- 当前人物生成、跨镜头一致性均为 `NOT_RUN`。

## 5. 场景与镜头规范

- 场景资产：江面、花林、孤舟、远山、晨曦、月光；每个场景保留参考图、色板、提示词、seed。
- 镜头时长：静帧 5-8 秒；Wan 英雄镜头 3 秒（73 帧）。
- 每篇作品：4-6 张静帧 + 1-2 段 Wan；Wan 只用于推近/环境动态。
- 不要求 Wan 完成精确主体位移（船/人物行走）。
- 每个镜头记录主体运动、相机运动、背景约束、结束状态。

## 6. 声音规范

| 项 | v1.0 |
|---|---|
| 旁白/朗诵 | CosyVoice 技术链路已验证（中文男进入成片）；中文女已合成/试听并固化方案，未进入正式成片 |
| 采样率 | 48 kHz |
| 响度 | 对白 -16 LUFS，真峰值 ≤ -1.5 dBTP |
| 语速 | 默认 1.0；按试听调整 |
| 背景音乐 | `NOT_RUN` / 待选型（R3-D）；有授权音乐时才加 |
| 音效 | `NOT_RUN` / 待选型（R3-D） |
| 音色克隆 | `NOT_RUN` |
| 女声选型 | `PARTIAL`：试听与韵律方案已完成；未进入正式成片；商用授权待核验 |

当前 R3 样片只有「中文男」朗诵，没有 BGM/音效；这是 v1.0 的已知缺口，不是“已完成”。中文女已完成本地合成、试听和韵律方案固化，但未进入正式成片，也不代表其他音色已验收。

R3-D 待完成范围：女声正式成片与商用授权、标题/点缀字体、BGM、音效。字体候选已完成来源/许可/覆盖/预览验证，字幕已接入正式构建，标题/诗词/现代解说仍为 `preview_only`，排版仍为 `DECISION`；女声已试听并固化方案但未入正式成片；BGM/音效未完成。

## 7. 字幕规范

- 格式：SRT（软字幕）+ ASS（烧录可选）。
- 每行 18-22 个中文字符，最多 2 行。
- 1080×1920：字号 56，底部安全区 180 px，白字黑边，无阴影。
- 字幕时间来自实际音频时长，不手写估算。
- R3-B 历史成片仍使用 Microsoft YaHei（**专有，商业分发前必须确认授权**），不是发布最终方案。
- 新构建的正式字幕入口 `scripts/r3_build.py` 使用 `config/fonts.yaml` 中的 Source Han Sans CN，并校验本地字体；R3-B 没重渲染。
- S3-B.1/S3-B.2 字体候选见下。
- 字幕不得遮挡主体脸部/月亮/关键动作。

### 7.1 字体候选（S3-B.1）

| 角色 | 候选字体 | 字重/字号候选 | 状态 |
|---|---|---|---|
| 古典标题 | Source Han Serif CN / 思源宋体 CN | Bold 或 Medium，120–170 px | `PARTIAL`（preview only）/ `DECISION` |
| 诗词正文 | Source Han Serif CN | Regular/Medium，64–76 px；行距 120–140 px | `PARTIAL`（preview only）/ `DECISION` |
| 现代解说 | Source Han Sans CN / 思源黑体 CN | Regular/Medium，50–56 px | `PARTIAL`（preview only）/ `DECISION` |
| 字幕 | Source Han Sans CN | Regular/Medium，52–56 px；底部安全 180 px；3 px 描边 | `PASS_VERIFIED`（正式构建）/ `DECISION`（最终视觉） |

来源/许可/字符覆盖/预览已通过；字体文件与哈希见 `assets/fonts/font_manifest.json`，报告见 `docs/R3D_FONT_SELECTION_REPORT.md`。字体授权不延伸到其他素材。

## 8. 视频母版规范

| 项 | 规范 |
|---|---|
| 画幅 | 9:16 |
| 分辨率 | 1080×1920 |
| 帧率 | 24fps |
| 编码 | H.264 High，yuv420p，CRF 18 |
| 音频 | AAC 48 kHz，192 kbps |
| 容器 | MP4，faststart |
| 时长 | 默认 30-60 秒；最长 90 秒仅实验 |
| 字幕 | 软字幕和/或烧录字幕 |
| 黑帧/损坏帧 | 0 |

1080×1920 当前由 576×1024 源经 FFmpeg Lanczos 放大，不是原生 1080p。

## 9. 内容真实性与标注

每条作品必须区分并记录：

1. **原文**：诗词/典籍原文，注明出处。
2. **现代解释**：白话释义/叙事改写，注明“现代解读”。
3. **历史事实**：有出处的服饰、器物、建筑信息；无出处则不得写成事实。
4. **艺术想象**：人物、场景、色彩、神话形象。
5. **AI 生成视觉**：画面由 FLUX/Wan 生成，不是历史复原。

发布时按平台规则标注 AI 生成内容；不得把 AI 想象写成考古/历史结论。

## 10. 内容验收清单

- [ ] 9:16 / 1080×1920 / 24fps
- [ ] 首帧、中帧、末帧无结构崩坏
- [ ] 主体与相机运动符合设计；H3 类主体位移单独核验
- [ ] 无颜色漂移、闪烁、黑帧、损坏帧
- [ ] 字幕可读、时间对齐、无错字
- [ ] 音频清晰，响度达标，无削波
- [ ] 原文/解释/想象/AI 标识正确
- [ ] 素材与字体授权已登记
- [ ] 平台封面/标题/文案与母版一致
