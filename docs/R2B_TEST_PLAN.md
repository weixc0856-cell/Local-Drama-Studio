## 2. 镜头设计

每个镜头必须同时声明**主体运动、相机运动、背景约束、结束状态**。

### H1 江面月光

| 项 | 内容 |
|---|---|
| 输入 | `assets/keyframes/kf01_river_first_moon.png` |
| 主体运动 | 水面波纹缓慢扩散；月光路径闪烁；薄雾从左向右漂移 |
| 相机运动 | 极缓慢推近（画面收紧约 2-3%） |
| 背景约束 | 河湾、远山、近岸芦苇位置不变；不出现新物体 |
| 结束状态 | 月亮略高；水面纹理与雾位置改变；构图略紧 |
| seed | 3101 |

提示词要点：相机缓慢推近；水波/月光/雾有真实运动；远山与芦苇固定；禁止 morphing / flicker。

### H3 孤舟向远山（重点）

| 项 | 内容 |
|---|---|
| 输入 | `assets/keyframes/kf03_lone_boat_night.png` |
| 主体运动 | 小船向远山方向划行，画面位置向右上移动，船体略变小，留下尾迹 |
| 相机运动 | **完全固定**：不许推拉、横移、变焦 |
| 背景约束 | 月亮、远山、芦苇、水岸线位置固定 |
| 结束状态 | 船相对首帧有明显位移（目标 ≥30 px @1024 宽） |
| seed | 3301 |

H3 的验收必须分离主体运动与相机运动：

1. 提示词明确 `camera is completely static`。
2. 用 `scripts/r2b_track_boat.py` 在中心 ROI 内追踪深色船体连通域质心，输出像素位移。
3. 人工看首/中/末帧确认船体形状未崩坏。
4. 若背景也发生位移，则不能把背景漂移当成船运动；该镜头记为 `PASS_LIMITED` 或 `FAIL`。

## 4. 验收记录

每镜头：

```text
job.json           prompt / seed / 输入关键帧 sha / 工作流 sha / 耗时 / 峰值显存
run.json           prompt_id / system_stats
clip.mp4           24fps，1024×576
quality.json       帧数/时长/编码解码/平均帧差/闪烁尖峰/黑帧
frames 首/中/末    人工检查
review.json        主体运动、相机运动、背景稳定性、颜色漂移、变形/闪烁、结论
```

状态定义：

- `PASS_VERIFIED`：技术全通过 + 主体/相机运动符合设计 + 无明显漂移/变形 + H3 位移达标。
- `PASS_LIMITED`：技术通过，但运动不足、颜色漂移、或需要后期处理才能用。
- `FAIL`：无法生成、解码失败、主体结构崩坏、H3 位移无法确认。
- `NOT_RUN`：未执行。
