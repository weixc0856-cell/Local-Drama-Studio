# R1 视觉设计规范：《春江花月夜》

> 实验片：约 90 秒，16:9，最终 1920×1080；本阶段只生产 768×432 的关键帧资产。
> 视觉方向：东方古典美学、电影级自然景观，水墨意境与写实质感结合。

## 1. 总体原则

1. **先景后人。** 本阶段不出现人脸特写；人物只作为远景剪影或舟中轮廓，避免把未验证的人脸一致性带进 R1。
2. **克制的颜色。** 以靛青、月白、墨色、青绿为主，淡金只用于晨曦与月光边缘；不使用高饱和青橙调色。
3. **水墨不是滤镜。** 只在远山边缘、雾气和留白处体现水墨感；近景水纹、花瓣、木舟保持写实纹理。
4. **时间有方向。** 月亮的升落、色温、雾气浓度必须沿一条连续时间线推进，不能每个镜头各自发挥。
5. **空间不跳。** 所有镜头共享同一条河湾、同一组远山、同一片近岸花林；镜头之间只改变视角与时间。

## 2. 主色调

| 名称 | 色值 | 用途 |
|---|---|---|
| 墨黑 | `#10161C` | 夜景阴影、远山剪影、画面边框 |
| 靛青 | `#1E3247` | 夜空、江水暗部 |
| 月白 | `#DCE6EA` | 月光、水面高光、雾 |
| 青绿 | `#4F6F63` | 近岸植物、苔石 |
| 雾灰 | `#8A9499` | 中景雾气、空气透视 |
| 淡金 | `#C9A76A` | 晨曦、月光边缘的暖调 |
| 胭脂淡 | `#8E5B5B` | 花瓣点缀，占比不超过画面 5% |

配色比例（夜景）：墨/靛 60%，雾灰 20%，月白 15%，青绿/胭脂 5%。
晨曦镜头允许淡金升至 25%，但不得出现纯橙或霓虹。

## 3. 光照规范

| 时间 | 主光 | 色温感 | 辅助光 | 雾气 |
|---|---|---|---|---|
| 江畔初月（黄昏后） | 低角度月光，冷银蓝 | 偏冷，保留一丝暮色暖调 | 天空残余微光 | 薄雾贴水面 |
| 花林月照 | 较高月光，侧逆光 | 冷银蓝 | 花瓣边缘的微弱高光 | 林间薄雾 |
| 孤舟远行（深夜） | 高角度月光，顶侧光 | 冷蓝，低对比 | 水面月光路径 | 江面平雾 |
| 落月晨曦 | 低角度暖光，逆光 | 淡金 + 冷蓝阴影 | 天空渐亮 | 较厚晨雾 |

硬性约束：

- 不使用现代影视常见的强烈轮廓光、霓虹补光、纯黑背景。
- 夜景阴影保留细节，不压成死黑；高光不溢出。
- 月光在水面形成一条连续的反射路径，方向与月亮位置一致。
- 云雾只做体积感，不做游戏 CG 式的发光粒子。

## 4. 画面质感

- 35mm 胶片颗粒，细而均匀；不做明显噪点。
- 轻微 halation（高光边缘柔化），只出现在月光与水面高光。
- 低微对比、柔和层次；远山使用空气透视逐渐褪色。
- 水面有细碎波纹与倒影，不是镜面。
- 花瓣、芦苇、木舟保留真实材质；避免塑料感和过度磨皮。
- 画面可以偏暗，但必须能看清近景结构。

## 5. 中国古典建筑与自然元素

允许：

- 唐代风格的低矮木构、茅亭、石阶、木栏、乌篷小舟。
- 江、河湾、沙洲、芦苇、青枫、桃/李花林、苔石、远山。
- 斗拱、素木、青瓦；不出现明清宫墙式的大红大金。

禁止：

- 现代建筑、电线、路灯、玻璃幕墙、水泥堤坝。
- 西方城堡、哥特尖顶、日式鸟居（除非明确需要，本项目不用）。
- 现代服饰、拉链、塑料制品、金属护栏。
- 不合理器物：青铜鼎、宫廷仪仗、与唐代民间江景不符的器物。

## 6. 摄影机语言

| 项 | 规范 |
|---|---|
| 画幅 | 16:9，本阶段 768×432，最终 1920×1080 |
| 帧率 | 24fps |
| 镜头 | 35mm 与 50mm 等效为主，少量 85mm 远景压缩 |
| 运镜 | 固定机位、缓慢推近、缓慢横移；避免快速摇镜与手持晃动 |
| 景别 | 大远景（江与山）、远景（孤舟）、中景（花林）、空镜 |
| 构图 | 三分法 + 大面积留白；地平线偏低或偏高，不居中 |
| 月亮 | 不总是居中；作为画面锚点，位置服从时间线 |
| 人物 | 只做远景剪影；不出现正脸、不出现现代服装 |

## 7. 时间线与月亮位置

设定：摄影机位于南岸，面向下游；东方在画面左侧，西方在右侧。月亮从左侧升起，向右侧落下。

| 关键帧 | 时间 | 月亮位置 | 色温 | 雾气 | 画面内容 |
|---|---|---|---|---|---|
| KF1 江畔初月 | 日落后不久 | 左侧低空 | 冷蓝 + 暮色淡金 | 薄 | 江湾、初月、远山、近岸芦苇 |
| KF2 花林月照 | 入夜 | 左上方 | 冷银蓝 | 林间薄雾 | 近岸花林、落花、月光 |
| KF3 孤舟远行 | 深夜 | 上方偏左 | 冷蓝、低对比 | 江面平雾 | 江心孤舟、远山、月光路径 |
| KF4 落月晨曦 | 黎明前 | 右侧低空 | 淡金 + 冷蓝阴影 | 较厚 | 落月、晨雾、江面渐亮 |

空间锚点：

- 河湾固定：近岸在画面下方，远山在画面上方偏右，花林在近岸左侧。
- 孤舟从画面中左向右远方移动，不逆向、不瞬间换岸。
- 远山轮廓在四个关键帧中保持同一组山峰关系；只允许因视角/焦距产生轻微变化。

## 8. 提示词规范

统一后缀（英文，供 FLUX 使用）：

```text
classical Tang-dynasty China, spring river landscape, ink-wash atmosphere blended with photoreal natural texture,
muted indigo-jade and moon-white palette, soft volumetric light, fine 35mm grain, cinematic 16:9 composition,
no people, no modern buildings, no text, no watermark
```

统一负向约束（在支持负向的模型/阶段使用）：

```text
modern architecture, power lines, neon, western fantasy, castle, oversaturated game CG, plastic look,
extra moon, distorted geometry, text, watermark, modern clothing, face close-up
```

场景提示词结构：

```text
[主体与动作] + [环境层次：近景/中景/远景] + [时间与光照] + [月亮位置] + [统一后缀]
```

禁止用“同一段提示词重复生成”来证明一致性；一致性必须来自参考图条件、固定视觉规范和人工比对。

```text

   ├─ KF2 花林月照   reference + 编辑指令：近岸花林，月光更高
   ├─ KF3 孤舟远行   reference + 编辑指令：江心孤舟，远山层次
   └─ KF4 落月晨曦   reference + 编辑指令：右侧落月，晨雾暖光
```

- 参考图只提供画风、色板、远山与河湾关系，不要求复制构图。
- 每个关键帧记录：prompt、seed、尺寸、参考图 sha256、耗时、峰值显存、输出 sha256。
- 人工检查项：月亮方向、河湾结构、远山轮廓、雾气浓度、是否出现现代物件。

## 10. 本阶段不做什么

- 不生成 1080p 原生画面；最终放大留给 R3。
- 不生成人物正脸、不验证人脸一致性。
- 不做视频生成（R2）。
- 不使用 SeedVR2 或其他未验证的超分/修复模型。
- 不为了“更美”引入新的风格模型或 LoRA。
