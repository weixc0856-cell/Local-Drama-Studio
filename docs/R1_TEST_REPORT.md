## 1. R1-A：审查结论

完整内容见 [R1_AUDIT.md](R1_AUDIT.md)。关键结论：

1. 现有 FLUX 工作流输入为 prompt/seed/尺寸/步数，输出单张 PNG；R0 已验证。
2. ComfyUI 0.43.0 内置 `ReferenceLatent`，官方 FLUX.2 klein 编辑模板使用
   `LoadImage → VAEEncode → ReferenceLatent → CFGGuider`。本阶段已在本机 Q4 + XPU 上实测。
3. 现有探针支持提交、参数替换、输出路径、结果下载、参数记录，但**没有断点续跑**。
4. 16:9 不需要改工作流，只改 `EmptyFlux2LatentImage` 与 `Flux2Scheduler` 的宽高。
5. 项目此前没有人物/场景一致性机制；本阶段用参考图条件 + 视觉规范 + 人工检查建立。

### 3.2 发现

1. **16:9 可行**：768×432 无需改工作流，约 70-102 秒/张，峰值显存 2.6-2.84 GiB。512×512 与 16:9 耗时接近，说明固定开销（文本编码器/模型加载）占主导。
2. **参考图编辑可用**：`ReferenceLatent` + `VAEEncode` 在本机 Q4 + XPU 上工作，J3/J4/J5/J11 均成功。
3. **参考图保留的是“地貌与色板”，不是像素级构图**：J3 的花林是新构图，但河湾与远山关系延续；J11 在保留 J2 河湾/远山的同时，把时间改成黄昏、月亮压低。
4. **纯文字也能得到接近的色板**：相同 seed + 统一 style suffix 的 J6/J7/J8 与参考图结果在色调上接近，但山形、岸线更自由；参考图在空间锚点上更稳。
5. **没有出现现代建筑、文字或水印**；人工检查通过。J4 中有一名远处舟中人影，无正脸。
6. **0 失败、0 重试**：11 个任务一次通过；R1-E 的删除恢复测试额外提交 1 次，也成功。重试路径（最多 2 次）未被实际触发，不能写成“已验证重试”。

## 7. 未验证 / 风险

1. **1080p 未验证**：本阶段只生成 768×432；1920×1080 放大留给 R3。
2. **视频未验证**：关键帧尚未喂给 Wan I2V；R2 才做。
3. **Wan 分辨率约束**：`Wan22ImageToVideoLatent` 的宽高必须能被 32 整除，768×432 的 432 不是 32 的倍数（432/32=13.5）。R2 必须改为 1024×576（16:9 且 /32）或 832×480，或先缩放/补边。
4. **长片段未验证**：73/121 帧的显存与耗时未知。
5. **人物一致性未验证**：本阶段没有正脸；R5 才处理。
6. **多参考图未验证**：官方模板支持链式 `ReferenceLatent`，本阶段只用单参考图。
7. **KF4 光源歧义**：暖色圆球可能是朝阳。
8. **月亮路径是示意**：不是天文精确轨迹。
9. **重试路径未触发**：代码有上限，但没有实际失败样本。
10. **未接入音乐、朗诵、字幕**：R6 范围。

## 8. 成本与 R2 建议

### 8.1 成本

- 11 张 768×432 / 512×512 图，总计约 15 分钟生成时间（含文本编码器加载）。
- 峰值显存 2.84 GiB，远低于 8 GB；FLUX 阶段不是瓶颈。
- 90 秒影片约需 10-15 张关键帧 + 返工，图像阶段约 30-45 分钟，可接受。

### 8.2 R2 第一组实验（不要直接生成整片）

1. 用 KF1-KF4 做 I2V，分辨率 **1024×576**（16:9，宽高均 /32）；若 OOM，再测 832×480 或 768×448。
2. 每镜头先测 **73 帧（约 3 秒）** 和 **121 帧（约 5 秒）**，20 步，记录耗时与峰值显存。
3. 固定 `uni_pc` / `simple` / shift 8 / CFG 5 / 20 步；10 步只用于排错。
4. 用关键帧作为 `start_image`，不要用纯文字替代首帧。
5. 观察人物/孤舟的运动幅度与背景稳定性；如果背景漂移，优先缩短镜头或降低运动描述。
6. 先不要做超分；等 R2 确认视频分辨率与时长，再在 R3 做 1080p 放大。

### 8.3 进入 R2 前的门槛

- 至少 2 个镜头在 1024×576 下完成 73 帧生成且可解码。
- 峰值显存 < 7.5 GiB，无 OOM。
- 关键帧到视频首帧的人物/船/山形不出现明显跳变。

## 9. 结论

`PASS_VERIFIED`（R1 范围内）：FLUX.2 klein 在本机可稳定生成 16:9 古典诗词场景；参考图条件可用于保持河湾/远山/色板；批处理支持参数记录、断点续跑与删除恢复；四张关键帧在空间与时间上成立。

保留项：KF4 光源语义、月亮路径示意性、无视频/1080p/人物一致性验证。按约束停在 R1，不进入 R2。
