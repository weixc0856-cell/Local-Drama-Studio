# 玄机式 3D 国漫 · 视觉要点（2026-11-08）

> 用途：`animation.xuanji_3d` 参考板的生成依据。**只做风格研究，不复制任何具体影片镜头、角色、服装纹样或素材。**
> 实现方式：提示词只描述可观察的视觉特征（材质、光位、景别、大气），不依赖作品名，也不写具体角色名。

## 1. 画面基底

- 电影级三维国漫：物理渲染（PBR）+ 次表面散射（SSS）+ 发丝级毛发 + 体积光；观感是「高预算 CG 动画帧」，不是实拍，也不是二维赛璐璐。
- 细节密度是签名：衣料暗纹、甲片高光、玉石与鎏金配件、发丝逆光、空气里的微尘与光斑。
- 场景按「大景 + 小人物」组织：远山、云海、城墙、断崖与前景残破构件共同撑起尺度。

## 2. 人物与面部

- 脸部走「动漫式比例 + 写实光照」：五官清晰、皮肤如瓷，暗部有暖红透光（SSS），不做毛孔与瑕疵。
- 眼睛有高光与虹膜层次，睫毛与眉毛分缕可见；嘴部表情克制。
- 头发是独立的美术资产：发束分组、有体积、边缘被侧逆光打出细亮边；风里呈缓慢飘动而非乱飞。
- 本项目没有角色一致性能力：本风格包只锁定「质感与光照」，不承诺同脸。

## 3. 服饰与材质

- 丝绸/锦缎：缎面高光、暗纹与凸起织金；颜色以靛蓝、绛红、墨黑为主，金线做点缀而不是铺满。
- 甲：黑漆鳞甲、银灰札甲片，边缘高光与磨损；皮革腰带、铜扣、绳结。
- 配件：玉、鎏金、雕漆、流苏；饰品质感必须比皮肤更「硬」。
- 场景材质：苔石、旧木、铜锈、崖壁岩层；远景用空气透视压成灰蓝。

## 4. 光与大气

- 主光多为侧逆光/轮廓光：人物边缘一圈暖金亮边，正面补光偏冷。
- 夜间/林间：深青绿色阴影 + 一盏暖色实用光（灯笼、火光），体积雾把光切成可见的光束。
- 黄昏/战场：低角度太阳、暖橙天空、逆光尘雾；天空云层有手绘般的体积与层次。
- 高光克制：不许过曝死白，不许塑料感高光；暗部保留青蓝而不是死黑。

## 5. 构图与景别

- 三种常用景别轮换：特写（面部/材质）、中景（人物与服饰全貌）、大远景（尺度与世界观）。
- 前景虚化构件（枝叶、碎石、旗幡、肩甲）压住画面边缘，中景是主体，远景是山与云。
- 低机位仰拍用于威压感；三分之四侧面用于展示服道化。
- 画幅：项目内关键帧为 9:16 竖构图，构图要按竖幅重新组织，不是横画幅裁切。

## 7. 与 `animation.mushenji_dark` 的分工

- `mushenji_dark`：棕黑低饱和的「暗黑国风」，残垣、茅草、玉琮纹、水墨渗染，偏世界观与废墟质感。
- `animation.xuanji_3d`：同一制作体系里的**高光面**——织金重彩、瓷肌发丝、体积光大景，用于人物与场面。
- 两者共用一套技术栈（FLUX 关键帧 + Wan 运动），只在风格包层面区分，不在代码里加分支。

## 8. 本机边界

- 关键帧：FLUX.3 576×1024，约 70 秒/张。
- 视频：Wan2.2 TI2V 5B，20 步、448×768、49/65 帧（safe8g）；慢推与轻微运镜可靠，精确位移不可靠。
