# 抖音 / 小红书：这条生产线的舒适区

> 状态：`DECISION` / 2026-11-07
> 前提：A750 8 GB + Wan 5B；能做 30–60 秒动态分镜/混合短片，不能做全 Wan 多镜头连续动画。
> 结论：舒适区是**“动态国画 / 诗画短视频 / 图文审美笔记 / 文化科普”**，不是 AI 剧情短片。

## 1. 平台规格（2026）

| 项 | 抖音 | 小红书 |
|---|---|---|
| 视频画幅 | 9:16，1080×1920 | 3:4（1080×1440）或 9:16（1080×1920） |
| 视频时长 | 15–30 s 完播最好；不低于 7 s | 15–60 s，推荐约 30 s |
| 帧率/编码 | 24/30 fps，H.264 MP4 | 30 fps，H.264 MP4，8–12 Mbps |
| 图文 | 6–9 张，9:16 | 3:4 封面，6–9 张（上限 18），单张 ≤5 MB 更快 |
| 封面 | 安全区约 1080×1464 | 3:4，标题 10–15 字，文字占比 ≤30% |
| 关键指标 | 前 3 s 完播、整体完播、复看、收藏 | 封面点击、收藏、评论质量 |

## 2. 舒适区内容（A 级）

| 内容 | 平台 | 规格 | 生产时间 |
|---|---|---|---|
| 一诗一画 / 山水空镜短视频 | 抖音、小红书 | 15–30 s，4–6 镜，1 个纯风景 Wan hero，其余静帧推拉+云水运动，旁白/字幕/环境声 | 1–1.5 h/条 |
| 动态国画壁纸 / 开屏 loop | 抖音、小红书 | 10–15 s，1–3 镜，循环，无旁白或一句 | 30–50 min/条 |
| 3:4 图文审美笔记 | 小红书为主 | 6–9 张关键帧 + 书法/诗句排版 + 过程/参数 | 20–40 min/条 |
| 24 节气 / 古建一角 / 水墨过程 | 双平台 | 图文 + 15 s 视频组合 | 30–60 min/条 |
| 文化科普 / 名句解读 | 抖音、小红书 | 30–60 s，静帧/地图/书法 + 旁白，1 个 Wan 可选 | 1.5–2 h/条 |

## 3. 条件可用（B 级）

| 内容 | 条件 |
|---|---|
| 人物抒情短片 | 人物近景静帧 + 背景云/光运动 + 慢推；不能做动作/对白 |
| 建筑/亭台展示 | 必须做 2.5D 分层视差；不要用 Wan 直接生成建筑运动 |
| 品牌氛围片 | 空镜 + 产品静帧 + 光效；产品不能有复杂运动 |

## 4. 不舒适区（C 级，不要接）

- 剧情短片：角色动作、对白、连续空间；
- 2–5 分钟全生成动画；
- 角色跨镜头同脸 / 连续剧集；
- 4K / 60 fps 交付；
- 建筑/产品结构必须精确的商业片（除非先做 2.5D 分层）。

## 5. 舒适区模板（15–30 秒）

```text
画幅：9:16，1080×1920，24/30 fps
镜头：4–6 个；1 个纯风景 Wan hero（约 5–6 s）；其余静帧 8–12% 推拉 + 云/水/树叶局部运动
转场：普通切点 0.5 s 叠化；匹配剪辑保持硬切
旁白：3–5 句，逐句字幕；总旁白 8–15 s
声音：持续环境声 + BGM（ducking）；切点 whoosh
第一帧：诗句/标题/最强画面，3 秒内给出信息
结尾：留 1–2 s 尾音/尾画面，方便循环
标签：AI 生成内容声明
```

## 6. 图文笔记模板（3:4）

```text
比例：1080×1440（3:4），整篇统一
张数：6–9 张
第 1 张：封面（诗句/标题 10–15 字，文字 ≤30%）
第 2–3 张：最强画面/细节
第 4–6 张：不同景别/局部
第 7–9 张：过程、参数、before/after、AI 声明
标题：10–15 字，具体利益/审美点
正文：诗句/出处 + 画面说明 + 制作方法
```

## 7. 合规

- 中国《人工智能生成合成内容标识办法》自 2025-09-01 施行：发布时主动勾选“内容由 AI 生成 / 笔记含 AI 合成内容”，不得篡改/隐匿平台标识。
- 抖音未主动标注可能限流、下架、取消营利；小红书可设置 → 内容类型声明。
- BGM 只用平台曲库或已登记 PD/CC 素材；不得抽取电影/动画原声。
- 配音/参考音、字体、图片素材逐项保留授权记录。

## 8. 一句话

**舒适区 = 15–30 秒“会动的国画” + 6–9 张 3:4 图文笔记 + 文化/诗词/节气系列。**
**不舒适区 = 角色剧情、2–5 分钟全生成、4K、角色同脸。**
