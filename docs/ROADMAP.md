# 08 · ROADMAP — v1.0 冻结与后续验证

> 文档状态：`DECISION` / v1.0 路线冻结（2026-11-03）。
> 已完成的是技术验证与单篇样片；未完成的是《洛神赋》、平台测试、批处理与数据闭环。

## 1. v1.0 冻结范围

### 冻结

- 产品定位：东方视觉内容生产工具。
- 内容范围：山水诗词 / 古典女性 / 神话幻想。
- 核心栈：ComfyUI + FLUX.2 Klein 4B + Wan2.2 TI2V 5B + CosyVoice + FFmpeg。
- 生产流程：单篇、人工审核、手动发布。
- 工程约束：双 venv、模型外置、无自动发布、无新依赖。
- 文档体系：本 8 份产品文档 + R0-R3 历史报告。

### 不冻结

- 具体画风优先级。
- 后续模型/插件/工具。
- 商业化模式。
- 自动化规模。
- 尚未验证的性能与市场指标。

### R3-D · 声音、字体、背景音乐与音效选型

状态：`PARTIAL`（字体候选与字幕接入已核验；女声已本地合成/试听并固化方案、未进入正式成片；BGM/音效与商用授权待完成）
定位：R3 是技术生产基线；R3-D 是内容审美与素材授权基线；《洛神赋》样片（本文件 M3，项目讨论中也称 R4）才是最终产品质量验收。
前置：R3 已提交 `0204979`；保留中文男声版本为基线；不修改生产脚本、不新增生成模型。

**A. 女声 TTS**

- 现有基线：CosyVoice-300M-SFT「中文男」。
- 候选：阿里云 Qwen TTS（温怀清、余小云）、火山引擎（古风少御 BV115、温柔淑女 BV104、知性女生 BV009）、ElevenLabs 付费对照。
- 同一段 20-30 秒《春江花月夜》文本试听。
- 评价：自然度、咬字、停顿、情绪、诗词韵律、生成稳定性、是否过度播音腔。
- 核实服务条款、套餐、音色授权、生成音频商用范围。

**B. 字体**

- 思源宋体：标题/诗词。
- 思源黑体：正文/字幕。
- 霞鹜文楷：少量古风点缀（未下载）。
- 思源宋体/黑体 CN 候选已下载并完成来源、许可、字符覆盖和竖屏预览验证；排版选型仍为 `DECISION`。OTF 二进制不进入 Git，由 `scripts/fetch_fonts.py` 按 manifest 哈希重建。
- R3-B 历史成片仍使用 Microsoft YaHei；新构建字幕已接入本地 Source Han Sans CN。字体 manifest/README/LICENSE 纳入 Git；OTF 由 fetch 脚本重建。

**C. 背景音乐**

- Pixabay、Mixkit 等候选来源；古琴、箫、古筝、东方氛围。
- 记录曲目页面、作者、下载日期、许可证、文件哈希。
- 检查 Content ID、署名、跨平台使用限制。

**D. 音效**

- Freesound 优先 CC0；水流、风声、鸟鸣、衣袂、钟磬。
- CC BY 需署名；CC BY-NC 不得用于商业项目。
- 逐条登记授权。

**E. 音频质量**

- 至少三种混音对照。
- Integrated LUFS、True Peak、语音/BGM 相对响度。
- 手机扬声器试听。

验收：选定 1 个女声音色 + 1 套字体 + 1 首 BGM + 1-2 个音效，均有授权证据；3 组字幕样式、3 组混音人工对比；LUFS/True Peak 达标；不改工作流、不进入完整样片。

### M3 · 《洛神赋》样片

目标：证明第二篇、不同题材也能走通完整流程。
前置：R3-D 完成；使用选定的女声、字体、BGM、音效。

验收：

- 45-60 秒，9:16，1080×1920。
- 4-6 张静帧 + 1 段 Wan（最多 2 段）。
- 原文/现代解释/艺术想象/AI 标识清楚。
- 使用 R3-D 选定的女声朗诵 + 字体/BGM/音效 + 字幕 + FFmpeg 合成。
- 人工完整看片通过。
- 记录端到端成本。

状态：`NOT_RUN`。

### M4 · 平台测试

目标：用 3-5 条作品分别测试抖音、小红书，建立第一轮真实数据。

验收：

- 每条有独立封面/标题/正文/话题。
- 记录 24h / 72h / 7d 的播放、完播、互动、收藏、涨粉。
- 至少 3-5 条同变量样本再判断趋势。
- 不把单条数据当结论。

状态：`NOT_RUN`。

### M5 · 夜间批次与内容包

目标：一晚产出一批可审片，而不是一条一条手工跑。

验收：

- 每篇独立目录/manifest；失败隔离；降级版本。
- 早晨输出成功/降级/失败清单 + 成本摘要。
- 不自动发布；人工审核。
- 至少 2 篇连续批处理成功。

状态：`NOT_RUN`。理论产能 6-8 篇/夜（基于 43.8 min/篇，未验证）。

### M6 · 数据反馈与迭代

目标：用真实数据决定内容方向，而不是凭感觉。

验收：

- 数据字段完整、可对比。
- 至少两轮“提出假设 → 发布 → 记录 → 调整”。
- 形成题材/风格/时长/封面的初步结论。

状态：`NOT_RUN`。

## 5. 暂缓

- 原生 1080p / SeedVR2。
- 复杂人物动画 / 数字人 / 口型同步。
- 多模型并行 / 新视频模型。
- Remotion / 复杂 Agent 框架。
- 自动发布 / 自动数据抓取。
- 商品转化系统。
- 无明确用途的数据库/向量库。

## 6. 决策门

在 M3 与 M4 完成之前：

1. 不扩大技术栈。
2. 不新增模型/插件/依赖。
3. 不追求原生 1080p。
4. 不开发自动发布。
5. 不把“单篇成功”写成“产品验证完成”。

## 7. 风险与依赖
