# 商业人像摄影与数字模特质量验收审核标准表 (PORTRAIT_QA_CHECKLIST)

> 版本：v1.0 (2026-11-19)
> 适用范围：Patreon、商业画报、全球神颜日更、超模高定等一切高质量人像生成与发布流程。
> 核心原则：**技术合格（Hard Metric）是底线，审美真实（Aesthetic Quality）是商品价值。** 杜绝自欺欺人，实行双重审核。

---

## 一、 快速红线初筛（任一不合格直接判定 FAIL）

| 检查项 | 判定标准 | 状态 | 常见缺陷表现 |
|:---|:---|:---:|:---|
| **五官严重崩坏** | 眼睛融解、大小眼显著不对称、瞳孔重叠、三眼皮畸变、嘴部畸变、牙齿色块 | [ ] | 低潜空间分辨率下强行大笑导致肌肉拉扯 |
| **手部肢体畸变** | 六指、断指、手指黏连融化、手臂关节反折、两个左手/右手 | [ ] | 手部未在提示词中交代明确动作或被画面边缘截断 |
| **严重结构伪影** | 衣物融进肉里、饰品与皮肤黏连、悬浮不合理物体、严重黑边与马赛克 | [ ] | LoRA 权重过高或步数过低 |
| **死机黑图/空图** | 文件损坏、全黑、纯色噪点图、低于规定尺寸 | [ ] | 工作流报错或显存溢出 |

## 二、 技术与真实感维度审核（客观细节）

### 1. 人脸结构与微表情真实度
- [ ] **骨相与肌肉逻辑**：面部起伏自然，鼻唇沟、颧骨、下颌角转折符合人体解剖，无过度膨胀的“充气硅胶感”。
- [ ] **眼神与高光（Catchlights）**：双眼视线方向一致，具备真实晶状体反光（环境光源映射），无空洞失焦。
- [ ] **神态自然度（杜绝苦相与假笑）**：眉宇舒展放松，嘴唇自然微闭或轻微呼吸微张（soft breathing repose），杜绝嘴角机械上扬形成的“影楼僵硬假笑”与下垂“苦相脸”。

### 2. 皮肤与微观材质（真实质感 vs 塑料橡皮人）
- [ ] **真实微观皮质**：保留细腻毛孔、微绒毛感与真实皮下血色（Subsurface Scattering），禁止“磨皮过度像蜡像或芭比娃娃”。
- [ ] **织物与服装物理质感**：丝绸有真实垂坠流光、呢子风衣有粗花呢纤维织纹、皮革有细微折痕与高光，避免色块贴图感。
- [ ] **发丝物理逻辑**：碎发与主要发束走向顺畅，有空气感与风向逻辑，发根与头皮交界自然，无整块板结发泥。

### 3. 肢体动作与道具物理逻辑
- [ ] **手部与道具真实接触**：端杯手指有力道支撑、执伞手掌有抓握弧度、托腮手腕与下颌贴合，无“虚空悬浮”或穿模。
- [ ] **体态力学**：重心稳定，斜倚或站姿符合人体站立力学，肩颈线条修长舒展。

## 三、 摄影与审美维度审核（商业价值）

### 1. 镜头差异性与景别多样化（拒绝 6 张同一张图变体）
- [ ] **景别分布梯度**：单套 6 张图中，必须涵盖至少 3 种不同景别与机位（如：胸腰中景、环境半身中远景、车窗/门廊框式中景、侧身回眸抓拍），严禁 6 张清一色同一距离。
- [ ] **体态与角度差异**：严禁 6 张全部正面对称站立。必须有 30°~45° 侧身、回眸、斜倚、坐姿等多元体态。
- [ ] **视线流动感**：视线包含望向侧方远景、低头凝视手中道具、侧首回眸、对视镜头等，全套充满电影剧照叙事流动。

### 2. 构图与画幅留白（Negative Space）
- [ ] **视线延伸留白（Lead Room）**：人物面朝方向有充足的呼吸空间（占画面 25%~35%），不贴画幅边缘。
- [ ] **头部留白（Headroom）**：发顶上方保留 10%~15% 呼吸空间，严禁误裁头顶或天花板空旷过大。
- [ ] **画中画与前景层次**：具备明确的“前景柔焦虚化 - 中景人物主体 - 远景环境景深”，三维空间感立体。
