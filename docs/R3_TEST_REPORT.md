## 2. R3-A：竖屏能力

### 2.1 结果

| Job | 类型 | 尺寸 | 耗时 | 峰值显存 | 结果 |
|---|---|---|---|---|---|
| V1 | FLUX 静帧（江月） | 576×1024 | 52.9 s（第 3 次尝试成功） | 2.63 GiB | 成功，竖屏构图正常 |
| V2 | FLUX 静帧（花林） | 576×1024 | 24.1 s | 2.79 GiB | 成功 |
| V5 | FLUX 静帧（远山） | 576×1024 | 22.1 s | 2.79 GiB | 成功 |
| V6 | FLUX 静帧（孤舟） | 576×1024 | 22.2 s | 3.53 GiB | 成功 |
| V7 | FLUX 静帧（晨曦） | 576×1024 | 22.2 s | 2.79 GiB | 成功 |
| V3 | Wan I2V（花林推近） | 576×1024 | 2185.0 s（36.4 min） | 5.48 GiB | 73 帧 / 3.042 s / 解码 0 |

- 竖屏 FLUX 无拉伸、无黑边；构图按 9:16 重新生成，不是横屏裁切。
- V1 的 3 次尝试是 ComfyUI 启动竞态（连接被拒绝），不是模型失败；第 3 次成功。
- 竖屏 Wan 73 帧 36.4 分钟，峰值 5.48 GiB；与横屏 1024×576（40-43 分钟）接近，但冷热启动条件不同，**不能据此宣称竖屏更快**。
- V3 技术质量：73 帧连续、编码/全帧解码通过、无黑帧、1 个闪烁尖峰；画面稳定，推近和花瓣运动有效。

### 2.2 结论

`PASS_VERIFIED`：576×1024 可作为竖屏生产规格；FLUX 与 Wan 均可用。

## 3. R3-B：单篇完整成片

### 3.1 结构

| 段 | 素材 | 时长 | 方式 |
|---|---|---|---|
| S1 | V1 江月 | 8.0 s | Ken Burns 推近 |
| S2 | V2 花林 | 5.0 s | Ken Burns 推近 |

| S4 | V5 远山 | 7.0 s | Ken Burns 推近 |

| S6 | V7 晨曦 | 8.0 s | Ken Burns 推近 |
| 合计 | | **38.042 s** | 5 静帧 + 1 Wan |

满足：30-60 秒、9:16、4-6 张静帧、Wan ≤2 段。

### 3.2 配音与字幕

- CosyVoice SFT，预置音色「中文男」。
- 7 句朗诵，逐句合成，总语音 29.99 秒，合成耗时 162.1 秒。
- 句首时间：1.000 / 7.071 / 11.621 / 16.670 / 20.779 / 26.095 / 31.934 秒。
- 字幕由实际音频时长生成 SRT，并额外生成 1080×1920 PlayRes 的 ASS 用于烧录。
- 烧录字幕字号 56，底部安全区 180 px；抽帧检查可读。

### 3.3 技术检查

| 项 | 结果 |
|---|---|
| 视频 | 1080×1920 / 24fps / 913 帧 / 38.042 s |
| 音频 | AAC 48 kHz，mean -17.7 dB，max -1.4 dB |
| 流 | 软字幕版含 video + audio + mov_text；烧录版含 video + audio |
| 全帧解码 | 软字幕/烧录版均退出码 0 |
| 文件 | 软字幕 20 MB，烧录版 19 MB |

### 3.4 人工检查

- 竖屏构图没有拉伸或黑边；远山、河湾、花林、孤舟、晨曦的视觉规范一致。
- 字幕在 3 s、14 s、33 s 抽帧可读，不被裁切。
- Wan 段为花林推近，运动自然，无颜色漂移或结构崩坏。
- 全片没有使用 H3 的“船向远山”镜头；孤舟用静帧 + 推拉，符合 R2-B 结论。
- 没有 BGM/音效；只有朗诵。

### 3.5 结论

`PASS_VERIFIED`：单篇 38 秒竖屏成片可正常观看；技术链完整（素材 → Wan → TTS → 字幕 → FFmpeg）。

## 4. R3-C：真实成本

### 4.1 端到端

从第一张 FLUX 提交（09:25:02）到最终 MP4（10:08:52）：**43.8 分钟**。

| 环节 | 耗时 |
|---|---|
| FLUX 5 张静帧 | 143.6 s（2.4 min） |
| Wan 1 段（73 帧） | 2185.0 s（36.4 min） |
| CosyVoice 7 句（合成） | 162.1 s（2.7 min） |
| FFmpeg 合成/放大/字幕 | 约 2 min |
| 其他/启动/切换 | 约 0.3 min |

> 人工检查与返工时间未单独计时；本次抽帧检查与报告撰写不计入 43.8 分钟。

### 4.2 失败与降级

- Wan：1/1 成功，未触发降级。
- FLUX：V1 因启动竞态重试 3 次；属于流程顺序问题，不是模型失败。
- 成片：软字幕与烧录版均解码成功。
- 降级方案（Wan 失败退回静帧）已设计但**未实际触发**，不能写成已验证。

### 4.3 夜间批次判断

- 单篇 38 秒成片约 44 分钟，其中 36 分钟是 Wan。
- 理论上 8 小时可跑约 10 篇；计入人工审核、重试和素材差异，保守估计 **6-8 篇/夜**。
- 这是基于单篇的外推，**多篇批处理未运行**。
- 结论：作为“每晚一个批次”的雏形可行，但需要下一阶段补批处理与内容包管理。

## 6. 限制

1. 只做了 1 篇样片，没有多篇批量、没有跨篇素材复用。
2. 没有 BGM/音效；只有朗诵。
3. TTS 使用预置音色，不是自定义克隆。
4. 1080×1920 是放大结果，不是原生 1080p；未测试 SeedVR2。
5. 静帧的“运动”是 Ken Burns，不是生成动作。
6. 烧录字幕依赖 Microsoft YaHei 字体；换机器需确认字体可用。
7. V1 启动竞态说明批处理需要显式等待 ComfyUI 就绪；本次靠重试恢复。
8. 内容仍以实验脚本组织，尚未迁移到 `content/<pack>/`；共享工作流与内容素材已在物理上分离。
