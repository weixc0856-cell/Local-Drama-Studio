# 日系电影感（新海诚式）· 视觉要点（2026-11-06）

> 用途：`artistic.japanese_soft` 参考板的生成依据。**只做风格研究，不复制任何具体影片镜头、角色或素材。**
> 实现方式：提示词以「剧场版动画背景 + 新海诚式」描述视觉特征，不依赖具体作品名。

## 1. 画面基底

- 实景照片打底，再以数字绘画覆盖：先用真实地点建立透视、材质与光位，再统一成动画色。
- 日常日本场景：道口、站台、河堤、通学路、阳台、电线杆与电线、便利店灯光、雨后路面。
- 「每一帧都是壁纸」来自细节密度：窗灯、路灯、云隙光、水洼雨滴、湿地反光、飘落花瓣。

## 2. 光与光学

- 镜头光晕（lens flare）是签名：星芒、光环、彩虹色散、景深虚化都被主动模拟，暗示摄影机存在。
- 强逆光、明暗对比、云隙光（god rays）；高光不炸、阴影保留蓝紫。
- 反射是叙事工具：车窗、水面、湿地、玻璃。

## 3. 天空与云

- 巨大积云/积雨云，边缘受光、云底深蓝紫；天空从深蓝过渡到青、品红、橙。
- 高频使用青蓝与紫色；黄昏与雨是常用情绪载体。
- 云要有体积与真实气象结构，不做贴图式平云。

## 4. 色彩与构图

- 高饱和但克制：深蓝主调 + 暖橙高光 + 品红过渡；避免霓虹赛博。
- 广角、宽画幅感、低机位仰拍天空；背景多静态或缓慢移动，让小的运动被看见。

## 5. 落到风格包

| 特征 | 字段 |
|---|---|
| 剧场版动画背景 | `identity` / `medium` |
| 巨云、蓝紫阴影、渐变天空 | `positive_anchors` |
| 镜头光晕、god rays、无过曝 | `positive_anchors` |
| 电线杆、湿地、反光前景 | `composition` |
| 青蓝 / 品红 / 暖橙 | `color_profile`（仅验证） |
| 云移、光闪、雨丝、草动 | `motion_profile` |

明确排除：平涂赛璐璐、Q 版人物、可读文字/招牌、霓虹赛博、写实皮肤、3D 渲染、灰蒙天空、HDR 过曝、欧美城市。
