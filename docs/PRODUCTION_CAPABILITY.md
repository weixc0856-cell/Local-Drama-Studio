# 生产线能力边界（Capability Statement）

> 状态：`DECISION` / 2026-11-07
> 适用范围：当前本机配置（Intel Arc A750 8 GB、Wan2.2 TI2V 5B、FLUX.3 Klein、VoxCPM2、FFmpeg、`r3_build`）。
> 结论先行：这条线**能稳定生产 30–60 秒竖屏动态分镜/混合短片**；**不能稳定生产全 Wan 生成的多镜头连续动画**。

## 1. 硬件与软件基线

| 项 | 配置 |
|---|---|
| GPU | Intel Arc A750，8 GB |
| 视频模型 | Wan2.2 TI2V 5B（GGUF Q4_K_M，20 steps，CFG 5，shift 8） |
| 图像模型 | FLUX.3 Klein（GGUF Q4_K_M，16 steps，CFG 1.0） |
| 语音 | VoxCPM2（48 kHz，CPU，RTF≈9.3） |
| 合成 | FFmpeg + `r3_build`（字幕、字体、响度、ducking、叠化） |
| 稳定 Wan 配置 | 448×768 / 49 帧 / 单段约 8–14 分钟 |
| 已失败 Wan 配置 | 576×1024 / 121 帧（device lost）；448×768 / 49 帧在建筑/人物上仍会变形或崩溃 |

| 能力 | 状态 | 证据 / 限制 |
|---|---|---|
| 8 镜头 / 47 秒竖屏混合成片 | ✅ 可重复 | `build-20261107-225921`，quality + acceptance PASS |

## 3. 三种生产模式

### 模式 A · 动态分镜 / Animatic（推荐默认）

- 规格：30–60 秒，6–12 镜，1080×1920。
- 画面：全部静帧 + 8–12% 推拉 + 云/水/树叶局部运动 + 0.5 s 叠化；
  可选 1 个纯风景 Wan hero 镜头。
- 用途：剧本节奏、旁白、字幕、音乐、镜头关系的验收版本。
- 时间：关键帧约 20 分钟；配音约 15 分钟；运动/合成约 5 分钟；
  若加 1 个 Wan 镜头，增加约 30–40 分钟（含重试）。
- 定位：**可靠交付**。它能证明叙事、声音、字幕、节奏，但不能证明“全生成动画”。

### 模式 B · 混合短片（当前最高质量）

- 规格：30–60 秒，6–8 镜。
- 画面：1–2 个纯风景 Wan hero 镜头 + 其余确定性运镜/局部运动。
- 条件：Wan 只用于无建筑、无人物、无复杂结构的镜头；每段必须过尾帧/顶带/亮度/白块 QC。
- 时间：每个 Wan 镜头 2–3 段，约 30–60 分钟；失败重试另计。
- 定位：**条件可用**。比 A 更有“活”的感觉，但仍不是全生成。

### 模式 C · 全 Wan 生成

- 规格：30–60 秒，6–8 镜，全部 Wan。
- 现状：`BLOCKED`。S02/S03/S04 的失败已经证明不是提示词微调能解决。
- 需要：24 GB 级显存 + Wan 14B / 首尾帧工作流，或更稳定的视频模型；
  或接受逐镜头多次重跑 + 人工筛选，但不可作为批量生产方案。

## 4. 实测时间与成本

| 环节 | 实测 |
|---|---|
| FLUX 576×1024 单张 | 约 2–2.5 分钟 |
| Wan 448×768 / 49 帧 / 段 | 约 8–14 分钟 |
| Wan 576×1024 / 121 帧 | 约 66–69 分钟；本机已出现 device lost |
| 确定性运镜 1080×1920 | 约 10–90 秒/镜 |
| TTS 单句（VoxCPM2 CPU） | 约 2 分钟 |
| `r3_build` 合成 | 约 1–3 分钟 |
| 8 镜 47 秒混合片（1 个 Wan） | 约 1.2–1.5 小时（不含失败重试） |
| 8 镜全 Wan | 约 3–6 小时，且失败率高，不可排期 |

## 5. 镜头决策规则

| 镜头内容 | 采用方式 |
|---|---|
| 纯风景、云雾、水面、远山 | Wan 可试；49 帧 × 2–3 段；必须过尾帧/顶带/亮度/白块 QC |
| 建筑、塔楼、宫殿 | 不用 Wan；静帧 + 推拉 + 云/光局部运动；或 2.5D 分层视差 |
| 人物、服饰、面部 | 不用 Wan；静帧 + 推拉/局部背景运动；人工重点审片 |
| 字幕/旁白特写 | 静帧 + 轻微推近；不追求生成运动 |
| 换场/同景别/反推向 | 0.5 s `xfade` 叠化 |
| Hero 镜头 | 只有干净前缀 ≥ 目标时长才允许进入成片 |

## 6. 质量边界

- 技术 PASS：分辨率、帧率、解码、黑帧、冻结、字幕流、旁白/字幕起点、混音。
- 内容 PASS：必须人工在 1080×1920 实际尺寸看片；当前 `PRD-FILM-006` 仍为 `PARTIAL`。
- 当前稳定成片 `build-20261107-225921` 的定位是**动态分镜/混合片**，不是全生成连续动画。
- 声音：默认 `my_voice_clean_v2` 已按用户确认登记为 `APPROVED`；BGM/音效听感与商用授权仍需逐项确认。

## 7. 升级条件

| 目标 | 需要的改变 |
|---|---|
| 30–60 秒全 Wan 连续动画 | 24 GB 级显存 + Wan 14B/首尾帧，或更稳定的视频模型 |
| 2–5 分钟全生成 | 更大显存 + 分段调度 + 一致性模型；当前不可行 |
| 建筑/人物真实运镜 | 2.5D 分层视差（当前硬件可做）或换模型 |
| 学习型超分 | 安装 ncnn-vulkan Real-ESRNet/Real-ESRGAN 并完成 A/B；默认仍 Lanczos |
| 角色同脸 | 参考图/角色 LoRA/首尾帧；当前不支持 |

## 8. 一句话结论

**这条生产线现在能做：稳定的 30–60 秒竖屏动态分镜/混合短片，带字幕、配音、环境声、叠化和技术 QC。**
**不能做：全 Wan 生成的多镜头连续动画，尤其是建筑/人物镜头。**
在当前 A750 8 GB 上，后者不是调参问题，是模型与硬件稳定性问题；继续硬跑只会产生墨团、白块和崩溃日志。

## 9. 适配场景（能接什么活）

| 场景 | 适配度 | 交付形态 | 关键限制 |
|---|---|---|---|
| 诗画/山水/空镜短片（如《登鹳雀楼》） | A · 可交付 | 30–60 s 竖屏，6–10 镜，1 个纯风景 Wan hero，其余静帧推拉+云水运动，旁白/字幕/环境声 | 画面是“会动的画”，不是人物剧情 |
| 动态海报 / 开屏 / 预告 | A · 可交付 | 10–20 s，3–5 镜，少量文字，强节奏 | 不依赖人物动作 |
| 朗诵 / 旁白类（audio-first） | A · 可交付 | 60–120 s，逐句字幕，静帧+微动+环境声 | 观众注意力在声音，画面是气氛 |
| 分镜预演 / 提案 animatic | A · 可交付 | 30–60 s，粗剪，临时配音，标“animatic” | 不作为最终成片 |
| 文化科普 / 图文叙事 | A · 可交付 | 60–120 s，静帧、地图、书法、字幕 | 需要信息设计，不靠镜头运动 |
| 人物抒情短片 | B · 条件可用 | 人物近景静帧+背景云/光运动+慢推 | 人物不能做动作；否则像 PPT |
| 建筑/亭台展示 | B · 条件可用 | 2.5D 分层视差（前景/建筑/远景） | 纯 Wan 会把结构画坏；需要分层资产 |
| 品牌氛围片 | B · 条件可用 | 空镜+产品静帧+光效 | 产品不能有复杂运动 |
| 剧情短片（动作/对白） | C · 不适配 | — | Wan 5B 无法稳定生成人物动作与连续空间 |
| 2–5 分钟全生成动画 | C · 不适配 | — | 显存与稳定性双重限制 |
| 角色同脸 / 连续剧集 | C · 不适配 | — | 无角色参考锁定/首尾帧 |
| 4K 交付 | C · 不适配 | — | 目标 1080×1920 |

## 10. 反 PPT 规则（仍用静帧时）

1. 每个镜头至少有“内部运动”：云、雾、水、树叶、光斑之一；纯静止只允许 ≤2 s 的刻意停顿。
2. 镜头必须有可见的摄影机运动：8–12% 推拉；不要全片统一方向，按景别递进。
3. 切点不按固定 5 秒：跟随旁白句读、音乐重音、动作匹配；普通切点 0.5 s 叠化。
4. 声音要粘合：持续环境声、切点 whoosh、BGM ducking；声音连续能显著降低画面跳切感。
5. 建筑/人物不要长时间全屏静止；必须用 2.5D 分层视差或局部背景运动。
6. 一部 30–60 s 片只放 1–2 个 Wan hero 镜头；不要把所有镜头都做成同一强度的推近。
7. 如果仍然像 PPT：减少镜头数、延长单镜、增加前景遮挡/层次，而不是继续加转场。

## 11. 不能接的活

- 需要角色表演、对白、动作连贯的剧情片；
- 2 分钟以上全生成动画；
- 角色跨镜头同脸；
- 4K / 高帧率交付；
- 建筑/产品结构必须保持精确的商业片（除非先做 2.5D 分层资产）。
