## 4. 设计与实际对照

| 镜头 | 设计的相机运动 | 实际 | 设计的主体运动 | 实际 |
|---|---|---|---|---|
| H1 | 极缓慢推近 | 几乎固定 | 水波/月光/雾 | 有，幅度小 |
| H2 | 缓慢推近 8-10% | 明确推近 | 花枝摆动/花瓣 | 有 |

| H4 | 固定/极缓慢 | 接近固定 | 暖光渐亮 | 略亮但偏冷 |

## 5. 生产判断

1. **混合方案成立，但运动控制是瓶颈。**
   - H2 证明“推近类”镜头可以稳定产出。
   - H3 证明“主体位移 + 固定相机”在 5B/Q4/73 帧下不可靠，措辞再明确也会偏离方向。
   - H1/H4 说明静态氛围镜头可以生成，但相机/光线变化很弱。
2. **成本**：32.6-46.4 分钟 / 3 秒镜头。4 个英雄镜头 2.62 小时。
3. **建议**：
   - 叙事上不要依赖 Wan 完成精确主体位移（船、人物）；这类镜头用后期合成/分层位移，或改为静帧推拉。
   - H2 类“缓慢推近”可以作为默认 Wan 英雄镜头。
   - H3 若要继续，优先重写为“船保持在画面中右、只让水光变化”，不要要求从中心驶向远山。
   - H4 的暖光变化可在 R3 用调色实现，不必依赖模型。
