# M8-B(2) 独立前景资产路线：不挖洞的分层

> 执行日期：2026-11-04
> 前置：[M8_B1_PLATE_SOURCE_REPORT.md](M8_B1_PLATE_SOURCE_REPORT.md)（结论：从静帧里抠前景再补底不可扩展）
> 状态口径：`docs/PRD.md` §0.2

## 0. 结论

**M8-B(2) = `PARTIAL`（技术通过，人工待审）。**

换一条路：**不从画里挖前景，而是生成一块带 alpha 的独立前景，叠在完整背景上。** 结果成立：

| 检查 | 结果 |
|---|---|
| 露洞 | **不存在**（`reveal_worst = null`，按构造为零：背景从未被挖掉任何东西） |
| 合成可信度 | 芦苇丛与画面的墨色、笔触、纸纹一致，alpha 边缘无白边（见 `inspect_F2_0143.png`） |
| 层间视差 | 实测：叠层的左缘多走 28 px、上缘多走 56 px；同一位置的背景特征只走约 18 / 49 px，**净领先约 10–13 px** |
| 时间连续性 | 帧间亮度最大跳变 0.215/255，与 A/E 同一包络 |
| 成本 | 资产生成 30.8 s（576×1024、4 步）+ 渲染 49.4 s |

这条路线把 M8-B(1) 的死结解掉了：**前景从不遮挡"需要露出的背景"**，所以补底问题根本不出现。代价是它也改变了构图——前景是新增内容，不是原画里的东西。

## 1. 做法

1. 用已验证的 FLUX.2 klein 文生图（`workflows/r0_flux_t2i_api.json`，未改动）生成"写意水墨芦苇丛、纯白宣纸背景、孤立主体、四周留白"。
2. 亮度键出 alpha：按测量到的纸白（第 75 百分位）与墨色下限做软阈值，再 1.2 px 羽化，裁剪到 bbox。生成图 576×1024 → 资产 555×663，alpha 覆盖 8.1%。
3. 渲染新变体 `F`：背景 = **完整原图**（不挖洞），前景 = 资产按 `alpha=0.49` 的相机变换放置；其余参数与 B/C/E 完全相同（同一相机、同一纸纹、同 6 s / 24 fps / 1080×1920）。
4. 叠加位置（归一化，t=0 时）：`[0.24, 0.58, 0.57, 1.02]`，即画面左下、近岸水面处，底部越出画框。

## 2. 视差是怎么产生的（与 B/C 的关键差别）

B/C 里每一层都是"从画里切出来的一块"，露洞来自"切块移动后旧位置露白"。
F 里前景是**新增图层**，背景完好无损，因此叠层怎么动都不会露出空洞——视差只体现在"前景相对背景多走了多少"。

测量方法：`F − E`（E 为同一渲染器、同一背景相机、无叠层的基线），差值即叠层足迹。

| 帧 | 足迹 bbox | 质心 |
|---|---|---|
| 0 | (264, 1153, 604, 1920) | (435.0, 1670.0) |
| 143 | (236, 1209, 601, 1920) | (426.9, 1695.0) |

左缘 −28 px、上缘 +56 px；按背景相机（1.048）推算同一位置应只走 −18 / +49 px。**净领先 10–13 px，来自 `alpha=0.49` 与 `alpha=1.00` 的比例差。**

注意：视差幅度取决于叠层离焦点的距离。这次芦苇接近画面中心（焦点 0.5/0.48），所以只有 10–13 px；M8-A 里靠画面右下角的枯树走的是 20 px 量级。**位置决定视差能不能被看见**，这一点要写进分镜规则。

## 3. 局限（必须写进契约）

| 编号 | 局限 | 影响 |
|---|---|---|
| L1 | 前景是**新增内容**，改变了原画构图 | 只适用于"设计时就带前景"的镜头；不能用于"必须保持原画一草一木"的复刻镜头 |
| L2 | 生成资产的墨色/重量可能与画面其它前景不一致（本次芦苇略淡于画中的枯树） | 需要一条"风格连续性"检查，且必须人工看片 |
| L3 | 亮度键只在"深墨压浅纸"时成立 | 若前景叠在暗背景上，或需要保留浅色元素，此法失效 |
| L4 | alpha 键参数（纸白、墨色下限、羽化）是派生资产的一部分 | 必须随资产记录，否则无法复现 |
| L5 | 视差幅度受放置位置限制 | 分镜阶段就要决定前景离焦点多远 |

## 4. 对 M8-B 契约的影响（与 B1 的 C1–C6 合并）

| 编号 | 结论 |
|---|---|
| C1 | `PlateSpec` 必须记录图层**来源**：`interpolated` / `inpainted` / `independent_asset` / `generated_background` |
| C2 | 前景层只允许 `independent_asset`；`locked` 区域不得跨层 |
| C3 | 补底只允许用于背景层，掩膜覆盖率上限（本机经验 ≤4%、单一材质） |
| C4 | 补底必须掩膜外逐像素还原原图 |
| C5 | 不同材质的洞不得合并成一次生成 |
| C6 | 每块板 / 每个资产记录：来源类型、工作流哈希、seed、steps、掩膜或键控参数、耗时 |
| C7 | **资产需要"锚点框 + 视差系数 + 上下边界"**，而不只是文件路径：放置位置决定视差幅度（L5） |
| C8 | 资产需要一条风格连续性检查（墨色/纸白/线宽），不能只靠人工（L2） |
